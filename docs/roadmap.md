# Roadmap

## Fase 1 (MVP actual)
- Auth, perfiles, ride request, offers, assign, tracking básico.
- Chat base y recomendación de precio por IA (reglas).
- Panel admin con KPIs iniciales.

## Fase 2
- Voz (STT/TTS), negociación automática por límites.
- Pagos Stripe/MercadoPago.
- Modo Ángel Guardián inicial + SOS discreto.

## Fase 3
- Scoring de confianza predictivo.
- Ruta segura multiobjetivo.
- Detección avanzada de riesgo/anomalías ML.
- Segmento empresas/comunidades verificadas.
